# LYDIA

Portfolio of Lydia Amadi, product designer. I design apps, dashboards and open-source tools.

One self-contained page (`index.html`): landing, selected work, case studies, work archive, about, writing and contact. No build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy

Cloudflare Pages: connect this repo, framework preset **None**, build command empty, output directory `/`.
